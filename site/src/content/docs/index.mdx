<p class="irit-name"><em>irit</em> is the Indonesian and Javanese word for frugal: getting the most out of modest resources.</p>

<section class="irit-section irit-measured">

## Measured on a laptop

`leanqc` against FastQC 0.12.1 on one file of 1 million reads, on an AMD Ryzen 5 PRO 4650U laptop.

<Measured />

On a GitHub-hosted runner the same comparison covered 40 module verdicts across four files, and
none differed from FastQC. How each number was taken is in the [benchmarks](/irit/benchmarks/).

</section>

## Eight tools, one job each

Sizes are the Linux x86_64 binaries of 0.5.0.

<dl class="irit-toollist">
<div>
<dt>[`sheetgen`](/irit/tools/sheetgen/)</dt>
<dd>Builds a pipeline's sample sheet from a folder of FASTQ files and checks it against the pipeline's own schema.</dd>
<dd class="size">6.4 MB</dd>
</div>
<div>
<dt>[`leanqc`](/irit/tools/leanqc/)</dt>
<dd>Read quality control with an offline HTML report, giving the verdicts FastQC gives; long-read views too.</dd>
<dd class="size">1.8 MB</dd>
</div>
<div>
<dt>[`isotable`](/irit/tools/isotable/)</dt>
<dd>Joins QC, assembly, typing and classification outputs (fastp, leanqc, QUAST, Shovill, Flye, CheckM2, GTDB-Tk, CoverM, mlst, AMRFinderPlus, Kleborate and more) into one graded row per isolate or MAG.</dd>
<dd class="size">3.1 MB</dd>
</div>
<div>
<dt>[`dblock`](/irit/tools/dblock/)</dt>
<dd>Downloads in parallel, verifies and pins reference databases such as GTDB-Tk, CheckM2, Kraken 2, Bakta and AMRFinderPlus, with a lock file.</dd>
<dd class="size">5.8 MB</dd>
</div>
<div>
<dt>[`seqplan`](/irit/tools/seqplan/)</dt>
<dd>Plans a sequencing run: isolates per run and cost per isolate at a target coverage, from cited kit outputs.</dd>
<dd class="size">1.0 MB</dd>
</div>
<div>
<dt>[`gtdbprep`](/irit/tools/gtdbprep/)</dt>
<dd>GTDB-Tk's ANI species check on a laptop, without the 85 GB skani database.</dd>
<dd class="size">4.0 MB</dd>
</div>
<div>
<dt>[`irit-mcp`](/irit/tools/mcp/)</dt>
<dd>Gives AI agents these tools and wrapped ones (Shovill, Flye, Medaka, MEGAHIT, MetaBAT2, CheckM2, GTDB-Tk, AMRFinderPlus, Kleborate, ...) as checked tools, and records every call in a replayable run record.</dd>
<dd class="size">6.9 MB</dd>
</div>
<div>
<dt>[`msascope`](/irit/tools/msascope/)</dt>
<dd>GPU-drawn desktop viewer for very large multiple sequence alignments.</dd>
<dd class="size">desktop app</dd>
</div>
</dl>

</section>

<section class="irit-section irit-install">

## Install

<div class="irit-install-grid">
<div>

### One command

Linux and macOS, no sudo (into `~/.local/bin`):

```sh
curl -fsSL https://raw.githubusercontent.com/dzulfikar08/irit/main/scripts/install.sh | sh
```

### Download a release

Get the archive for your system from the [latest release](https://github.com/dzulfikar08/irit/releases/latest):
Linux x86_64 and ARM64, macOS Intel and Apple Silicon, or Windows. Unpack it and put the binaries on
your `PATH`. The Linux builds are statically linked, so they run on old distributions too.

</div>
<div>

### Build with Cargo

```sh
cargo install \
  --git https://github.com/dzulfikar08/irit \
  sheetgen leanqc isotable dblock seqplan irit-mcp gtdbprep
```

Or run `cargo build --release` in a checkout; the binaries land in `target/release/`.

</div>
</div>
