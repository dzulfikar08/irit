# Synthetic FASTQ corpus

Small files that each isolate one behaviour, compared with FastQC 0.12.1 by `tests/corpus.rs`
(part of `cargo test`). See [docs/benchmarks.md](../../../docs/benchmarks.md#synthetic-corpus).

- Generated by `scripts/make_fastq_corpus.py` from fixed seeds (rerunning gives the same bytes).
- `fastqc_verdicts.tsv`: FastQC's verdicts, recorded by `scripts/fastqc_corpus.sh` (needs Docker).
- `expected_differences.tsv`: the deliberate differences, with reasons. Any other difference fails
  the test.
